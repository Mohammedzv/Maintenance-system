# نظام إدارة صيانة ماكينات الخياطة — بدون تسجيل دخول

## الملفات
- `index.html`: واجهة النظام.
- `style.css`: التصميم.
- `firebase.js`: إعدادات مشروع Firebase الحالي `sstmy-627dc`.
- `app.js`: إدارة الماكينات وسجل الصيانة وقطع الغيار.
- `firestore.rules`: قواعد Firestore لهذا الإصدار بدون تسجيل دخول.

## التشغيل
1. ارفع الملفات على GitHub Pages أو استضافة تدعم HTTPS.
2. في Firebase Console افتح المشروع `sstmy-627dc` ثم Build → Firestore Database → Rules.
3. انسخ محتوى `firestore.rules` واضغط Publish.
4. افتح الموقع. لا توجد صفحة دخول؛ يفتح النظام مباشرة.

## تحذير أمني مهم
هذا الإصدار يفتح القراءة والكتابة على مجموعتي `machines` و`maintenance` لأي شخص، لأنك طلبت إزالة تسجيل الدخول مع إبقاء البيانات مشتركة أونلاين. بالتالي أي زائر يستطيع إضافة أو تعديل/حذف البيانات عبر أدوات مناسبة، وقد تتعرض قاعدة البيانات للتخريب أو الاستهلاك. لا تستخدمه لبيانات حساسة أو إنتاجية. الحل الآمن هو تسجيل الدخول أو وسيط خادمي يطبق الصلاحيات.

## قاعدة البيانات
الإصدار يستخدم **Cloud Firestore** وليس Realtime Database. لا يحتاج إنشاء مشروع جديد؛ إعدادات مشروع `sstmy-627dc` موجودة في `firebase.js`.
